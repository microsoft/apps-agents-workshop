**Intelligent Apps Catalog**
============================

A unified, open-source toolkit for building modern, intelligent, and scalable business applications.

The **Intelligent Apps Catalog** helps teams accelerate innovation by offering a structured, repeatable way to create intelligent user experiences, explore solution patterns, and share reusable components. Whether you're building **canvas apps**, **model-driven apps**, or **code-first applications**, this catalog brings your tools, prompts, and solutions together in one seamless experience.

> **Note:** This is sample code and not an official release. Refer to the official Generative pages [documentation](https://learn.microsoft.com/en-us/power-apps/maker/model-driven-apps/generative-pages)

🚀 **Overview**
---------------

This toolkit is built around **three core components**, each crafted to simplify development, enhance collaboration, and supercharge productivity:

*   **Prompt Catalog**
    
*   **App Catalog**
    
*   **Use Cases Catalog**


    



📌 **1\. Prompt Catalog**
-------------------------

The Prompt Catalog provides a guided, prompt-driven workflow that helps teams design AI-enhanced user experiences. Instead of building UI screens from scratch, users can explore a collection of prompt templates, follow a structured flow to generate pages, and use reference images—such as sample UX layouts—to maintain design consistency.

This component acts like a **UX co-pilot**, helping creators quickly produce clean, modern, and visually aligned interfaces.

### **Key Capabilities**

*   Browse a library of **pre-built prompt templates**
    
*   Follow a **guided prompt sequence** to generate UI screens
    
*   Upload or download **reference images** (e.g., UX samples like a Kanban board)

*   Redirect to the specific gen page to give user a **runtime experience **
    
*   Quickly create **consistent, visually aligned app interfaces**
    
*   Generate UX pages aligned with **modern design patterns**

🧭 **2\. App Catalog**
----------------------

The App Catalog serves as a centralized App Hub where users can access and launch all types of applications—canvas apps, model-driven apps, and Power Apps Code apps—all in one place. By embedding these apps directly into the hub, teams can explore solutions without navigating across environments.

This creates a smooth, unified experience ideal for demos, onboarding, training, and cross-team app discovery.
    

### **Benefits**

*   One-stop entry point for your **entire app ecosystem**
    
*   Faster app discovery across teams and departments
    
*   A clean, consistent user experience
    
*   Ideal for **demos, training, onboarding,** and app exploration
    

The App Catalog serves as a powerful **internal application showroom** for organizations.

📚 **3\. Use Cases Catalog**
----------------------------

The Use Cases Catalog is a shared repository where organizations can publish solutions, templates, reusable components, and best practices. It allows teams to document real use cases, link to downloadable solution packages, and maintain a centralized knowledge store.

By reusing proven patterns and shared assets, teams can accelerate development and reduce duplication of effort. This catalog functions as a **knowledge base + solution marketplace**, tailored to your organization’s development needs.

### **What Teams Can Do**

*   Document **company-specific use cases**
    
*   Upload or link to solution packages, components, connectors, and samples
    
*   Maintain a shared library of **best practices**
    
*   Accelerate development by **reusing proven assets**
