# Workshop prerequisites

Use these shared prerequisites before starting any workshop lab.

## General requirements

- Access to a Power Platform environment where you can create and run apps, agents, flows, and Dataverse assets.
- A licensed user account with the permissions required for the lab you are running.
- A modern browser such as Microsoft Edge or Google Chrome.
- Access to the workshop repository files, including the `solutions` folder when a lab depends on shared sample solutions.

## Environment guidance

1. Go to <https://make.powerapps.com>.
2. Select the environment you will use for the lab.
3. Confirm you have the required maker permissions before continuing.

## Shared solution setup

Some labs depend on the shared Northwind Traders sample solution.

- If your lab instructs you to import the Northwind Traders solution, follow the setup steps in [solutions/README.md](../solutions/README.md).
- Use the `solutions` folder as the source of truth for importing the shared solution and seeding sample data.

## Generative AI note

> [!NOTE]
> Labs that use generative AI features may produce different results between users and between the documentation and the live experience. If results vary, complete the task based on the intended outcome and the UI you see.
